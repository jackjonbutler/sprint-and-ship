# /sprint (deprecated)

This command has been replaced by GSD-style fresh-context execution:
1. /sprint-plan — order the Current sprint, write the manifest to the sprint page
2. /clear
3. /next — execute one ticket, then stop
4. Repeat /clear + /next until done
Tell the user this and offer to run /sprint-plan now.
